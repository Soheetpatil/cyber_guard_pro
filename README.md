# 🛡️ Cyber Guard Pro – Cybersecurity Awareness Web Tool

A lightweight cybersecurity awareness web project designed to simulate basic phishing risk detection and educate users about unsafe or suspicious text patterns.

## 🌐 Live Demo

👉 https://soheetpatil.github.io/cyber_guard_pro/

## 📌 Overview

Cyber Guard Pro is a frontend-based cybersecurity awareness project that demonstrates how suspicious messages can be analyzed for potential phishing indicators.

The goal of this project is to improve cybersecurity awareness by helping users understand how malicious messages can be identified using simple rule-based logic.

## ✨ Features

* Simple and clean cybersecurity-themed UI
* Phishing awareness simulation concept
* Basic risk analysis visualization
* Educational cybersecurity interface
* Lightweight and fast static website
* Hosted using GitHub Pages

## 🧠 How It Works

1. User interacts with the interface
2. Input message is analyzed (basic logic or rules if implemented)
3. System highlights possible risky patterns
4. Awareness-based output is displayed
